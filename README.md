# Fedora Dev Environment

My personal reproducible Fedora development environment.

The goal of this project is to automate the setup of my Linux workstation
while learning Linux, Bash, development tooling, and system configuration.

## Current environment

- Fedora Linux
- GNOME
- Zsh
- Starship
- JetBrains Mono Nerd Font
- tmux
- Vim
- Git
- fzf
- ripgrep
- eza
- bat

## Project philosophy

Manual setup → understand → automate → document.

Every new tool or configuration added to my workstation should eventually
be reproducible through this repository.
